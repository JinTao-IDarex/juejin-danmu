# Brand Spec · 掘金弹幕（juejin-danmu）

## 产品是什么
「掘金弹幕」是一个 Chrome 扩展（Manifest v3，v2.13.1），在掘金（juejin.cn）技术社区页面上叠加一层透明背景的"角色行走弹幕墙"——60 款像素/动漫角色在页面底部走来走去，配合弹幕评论飘过。气质：开发者社群 + 二次元弹幕文化 + 轻松有趣。

## Logo 使用场景（硬约束）
- Chrome 扩展商店图标 + 浏览器工具栏图标：**16 / 32 / 48 / 128 / 256 px**，必须方形、必须在 16px 下仍可辨认
- 油猴脚本弹层 logo、README 配图
- 需要同时经得起浅色页面和深色页面

## 品牌 DNA（从现有资产抽取，三版都必须保留）
现有资产：`../juejin-danmu-icon.png`（2000×2000）、`../icons/icon*.png`（在用图标）、`../tmp/juejin-brand/logo-mark.svg`（掘金官方 logo，色值 #1E80FF）

| 元素 | 规格 | 说明 |
|---|---|---|
| 主色 | 掘金蓝 **#1E80FF**（现用图标实际取色 ≈ #2E7CF6，统一回归品牌蓝 #1E80FF） | 掘金社区品牌蓝，是"掘金"身份的锚 |
| 母题 | **白色圆角弹幕条**（3 条横向圆角矩形，长短不一） | 弹幕/评论的可视化——产品核心是"弹幕墙" |
| 点缀 | **黄色圆点 #FFC526**（现取色 ≈ #F7C325） | 弹幕发送者头像/高亮点，是画面里唯一的暖色，必须保留 |
| 底板 | 方形图标底 | 现用是全出血直角方形 → 优化方向：现代应用图标的圆角底板（squircle/大圆角） |

## 现有 logo 的诊断（为什么优化）
1. **全出血直角方形**——在 Chrome 工具栏/商店里显得生硬，缺少现代图标体系（macOS/Chrome 新版均为圆角容器）
2. **三条横条读作"文本列表/文档"**，不像弹幕——缺少"评论气泡"的语义
3. **黄点游离**在画面最左缘，与弹幕条脱节，构图上像误放的小数点
4. **重心失衡**——内容簇整体偏下，上方 1/3 空白；视觉不居中
5. **小尺寸退化**——16px 下三条细白条糊成条纹，无法辨认

## 禁区
- ❌ 不改主色（必须是掘金蓝 #1E80FF 系）
- ❌ 不丢白色弹幕条母题、不丢黄色圆点点缀
- ❌ 不用紫渐变/emoji/通用 AI 风格（反 slop）
- ❌ 不模仿 Bilibili 电视机的具体造型（弹幕文化参照可以，造型必须原创）
- ❌ 三条弹幕条的"长短参差"节奏是现有 logo 的记忆点，尽量保留其节奏感
